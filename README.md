# SCSC — Sistema de Ciberseguridad Cuántica
**Project Entropy (Codename)**

## 📌 Descripción General
SCSC es un sistema experimental de ciberseguridad avanzada que integra principios de computación distribuida, criptografía moderna y simulación cuántica para el análisis, defensa y recuperación ante incidentes en infraestructuras digitales.

Este proyecto forma parte de una iniciativa mayor orientada al desarrollo de tecnologías de seguridad resiliente frente a amenazas emergentes, incluyendo escenarios de alta complejidad como ataques coordinados, fallos sistémicos y entornos degradados.

## 🎯 Objetivos del Proyecto

### Objetivo General
Desarrollar y validar un prototipo funcional de sistema de ciberseguridad basado en principios cuánticos y arquitecturas distribuidas.

### Objetivos Específicos
- Simular entornos de ataque en redes convencionales
- Implementar mecanismos de defensa automatizada
- Diseñar un sistema de recuperación ante fallos
- Evaluar resiliencia en arquitectura distribuida (cluster)
- Integrar modelos básicos de simulación cuántica

---

## 🧱 Arquitectura del Sistema

El sistema se basa en un **cluster distribuido de múltiples nodos**, donde cada componente cumple una función específica:

### 🔹 Componentes principales

- `app.py` → Punto de entrada del sistema
- `orchestrator.py` → Coordinador general del sistema
- `scheduler.py` → Planificación de tareas distribuidas
- `crypto_engine.py` → Motor criptográfico
- `attack_simulator.py` → Simulación de ataques
- `traffic_simulation.py` → Generación de tráfico de red
- `fault_tolerance.py` → Sistema de tolerancia a fallos
